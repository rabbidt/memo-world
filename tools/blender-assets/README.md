# Blender asset pipeline

Everything in `web/assets/models/` is generated by these scripts with Blender 5.1 run headless.
No textures are used: colour comes from materials, so the GLBs stay small.

```bash
blender -b --factory-startup --python build.py -- world ../../web/assets/models
```

```bash
blender -b /path/to/copy/of/wolf3.blend --python wolf_build.py -- ../../web/assets/models
```

```bash
blender -b --factory-startup --python compose.py -- ../../web/assets/models ../../docs/blender-previews
```

- `memo_lib.py`: primitives, the `Part`/`Asset` classes and GLB export.
- `memo_world.py`: locations and props (library tower, workshop, den, notice board, pond, garden plot, computer
  desk, lantern, bench, trees, walls, paths and so on).
- `wolf_build.py`: turns a **copy** of Rob's wolf model (`ATLAS/wolf/out/wolf3.blend`, not in this repo) into the
  four growth-stage GLBs. It decimates the sheet-matched meshes, converts the flat colours to lit materials,
  darkens the fur, adds the notebook and groups pieces into the nodes the game animates.
- `compose.py`: places the models on a stand-in island, writes `layout.json` (suggested dressing in game space)
  and renders the previews in `docs/blender-previews/`.
- `preview.py`: renders a line-up of any GLBs.
- `memo_char.py`: colour helpers, plus the earlier non-wolf character concepts (unused).

Conventions: 1 unit = 1 metre, +Y up, origin at ground centre, front facing +Z. `manifest.json` lists every
model with its size, triangle count and node pivots. Character nodes: `Body` (with `EyeL`, `EyeR`, `ArmL`,
`ArmR`, `Tail` as children and `Notebook` under `ArmR`), `FootL`, `FootR`. The wolf has no `Sprout`.
Models with a light have an empty named `Light` where a point light belongs.
