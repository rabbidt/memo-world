# Hand-made models

Everything here is generated by the Blender scripts in `tools/blender-assets/` (see its README) and listed in
`manifest.json` as `{ "models": [ { "name": "library_tower", "file": "library_tower.gltf", ... } ] }`.
`name` is the kind of object. `file` is a `.glb`, or for textured models a `.gltf` with a `.bin` beside it and
textures shared from `_tex/`. Load either with GLTFLoader.

Conventions: 1 unit = 1 metre, +Y up, origin at the centre of the ground, facing +Z.

Optional child nodes are exported at scale 0.001 (invisible). Set their scale to 1 to show them, and scale the
one you are replacing down again:

- Trees: `Canopy_spring`, `Canopy_summer` (visible by default), `Canopy_autumn`, `Canopy_winter`.
  Pines have `Canopy_summer` and `Canopy_winter`. Shrubs use `Leaves_*`.
- `garden_plot`: `Crops_spring`, `Crops_summer` (default), `Crops_autumn`, `Crops_winter`.
- Roofed buildings: `Snow`.

Trees, shrubs and walls each have a `_lod1` version for distance. `Light` empties mark where point lights go.
Water on `pond` and `waterfall` is a separate `Water` node with flow UVs (`Foam` too on the waterfall);
`campfire` has a `Flame` node; `observatory` has a `Dome` node that can turn; `computer` has `Screen`.

Ash: `memo_pup`, `memo_young`, `memo_growing_up`, `memo_grown`. Nodes `Body` (children `EyeL`, `EyeR`, `ArmL`,
`ArmR`, `Tail`; `Notebook` under `ArmR`), `FootL`, `FootR`. He is a blockout stand-in for now.

`layout.json` is a suggested placement of everything in game space (x, z, rotY, scale).
